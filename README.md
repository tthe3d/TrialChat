# 💬 TrialChat

> **Status:** This add-on is still in development.

TrialChat lets nearby players, including trial accounts, chat with one another when they have the add-on installed.

## Use

- Type `/tc` or click the minimap button to open the window. A keybind is available in the game's keybind menu.
- Use **Settings** from the minimap menu or the gear button to configure chat bubbles, nearby-chat echoes, minimized chat, and sound emotes.
- Nearby messages can be echoed to `/s` or `/p` for players who do not use TrialChat. Emotes are not echoed.
- Type normal WoW emotes such as `/wave`, or use the smiley button to browse and insert emoji and emotes.
- Type `//name` for a sound emote, such as `//laugh` or `//cheer`. See [Media/SoundEmotes/README.txt](Media/SoundEmotes/README.txt) for adding sounds.
- Create or join groups, invite players, synchronize group history, choose group icons, and manage members from the group menus.
- Right-click a nearby player or group member to start a TrialChat whisper. Whispers remain separate for each character.
- Right-click messages to reply or copy their text.

## Features

- Proximity chat using friendly nameplates, saved listeners, and group members.
- Chat bubbles for nearby and group messages, including group-colored bubbles.
- Group chat with saved history, offline reconnection, invites, member management, and synchronization.
- Minimal chat view with unread notices, scrolling, drag and resize support, and typing shortcuts.
- Chat history for up to 1,000 nearby messages and 2,000 group messages.
- Interactive links for webpages, items, quests, and Musician songs.
- Sound notifications, sound emotes, and searchable emoji and emote pickers.
